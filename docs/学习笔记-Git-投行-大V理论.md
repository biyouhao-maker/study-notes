## 1. Git 核心逻辑（块1）

### 1.1 心智模型：三个区域 + 四种对象

文件在四个地方之间流动：**工作区 →（git add）→ 暂存区 →（git commit）→ 本地仓库 →（git push）→ 远程仓库**。理解了这条流水线，80% 的 Git 问题都能自己想明白。

Git 内部只有四种对象，全部通过 SHA-1 哈希寻址：
- **blob**：文件内容的快照（不是 diff！Git 存的是整个文件的快照，未变动的文件只存指针）
- **tree**：目录结构（指向一堆 blob 和子 tree）
- **commit**：一次提交 = 指向一个 tree + 指向父提交 + 作者/时间/说明
- **tag**：指向某个 commit 的命名标记

由此推出几个反直觉但重要的事实：
- **分支只是一个指向某个 commit 的 41 字节文本文件**，所以创建/切换分支几乎零成本——Git 让你"随便开分支"不是鼓励，是设计如此。
- **HEAD** 是指向"你当前所在分支"的指针。`detached HEAD` 状态就是 HEAD 直接指向了某个 commit 而不是分支，此时提交的 commit 没有分支引用它，切走后会被回收（除非新建分支接住）。

### 1.2 命令分层学习路线（按周推进，不要一次背完）

| 阶段 | 命令 | 要点 |
|---|---|---|
| 第1天 | `init` `clone` `status` `add` `commit` `log` | 建立"每天 commit"的肌肉记忆 |
| 第1周 | `branch` `switch` `merge` `.gitignore` | 理解分支=指针；`.gitignore` 要在第一次 commit 前写好 |
| 第2周 | `remote` `push` `pull` `fetch` | `pull = fetch + merge`；先 `fetch` 看一眼再决定怎么合，是好习惯 |
| 进阶 | `rebase` `reset` `revert` `stash` `cherry-pick` `tag` | 见下 |

进阶命令的关键区别（面试和实际都爱考）：
- **merge vs rebase**：merge 保留分叉历史、产生合并提交；rebase 把你的提交"搬到"目标分支末尾，历史变成一条直线。**黄金法则：已经推送到公共分支的提交不要 rebase**，否则别人的历史和你对不上。
- **reset vs revert**：`reset --soft/--mixed/--hard` 分别保留/保留/丢弃改动，是**改写本地历史**；`revert` 生成一个"反向提交"来撤销，**不改写历史**，公共分支上要用它。
- **救命三件套**：`git reflog`（找回一切"消失"的提交，reset 错了 30 分钟内必能救回）、`git bisect`（二分查找引入 bug 的提交）、`git blame`（看每行是谁写的）。

### 1.3 团队协作工作流（三种主流）

- **GitHub Flow**（最常用）：`main` 保持随时可发布 → 开短命分支 → 提 Pull Request → 代码评审 → 合并 → 部署。适合 Web 项目和大多数团队。
- **Git Flow**：`master`/`develop`/`feature`/`release`/`hotfix` 五类分支。适合有明确版本号发布节奏的软件（App、固件）。
- **Trunk-Based Development**：所有人往主干提交极短生命周期的分支，用 feature flag 控制未完成功能的可见性。大厂主流。

Commit message 用 **Conventional Commits** 规范：`feat:` 新功能、`fix:` 修bug、`docs:` 文档、`refactor:` 重构、`test:`、`chore:`。一周后你会感谢自己。

### 1.4 实操建议（针对你的情况）

1. 从今晚起，把课程笔记和代码作业全部用 Git 管理，每天至少一个 commit。
2. 交互式练习一次：**Learn Git Branching**（pcottle.github.io/learnGitBranching，游戏化过关，2小时通关基础+远程篇）。
3. 系统读物：**Pro Git 中文版**（git-scm.com/book/zh/v2，官方免费开源书），只读前 3 章即可覆盖 90% 日常。
4. 出错了查 **dangitgit.com**（"Oh Shit, Git!?!"中文章，按"我犯的错"索引）。
5. 里程碑目标：一个月内给任意开源仓库提一个 PR（从改 README 错别字开始也算）。

## 3. 投行地基：会计三表（块3）

> 为什么投行培训从三表开始：估值和建模全部建立在三表之上。不懂三表勾稽，DCF/LBO 都是空中楼阁。

### 3.1 三张表各自回答什么问题

| 报表 | 回答的问题 | 记账基础 | 视角 |
|---|---|---|---|
| 利润表 Income Statement | 一段时间内**赚不赚钱** | 权责发生制 | 流量 |
| 资产负债表 Balance Sheet | 某一时点的**家底** | — | 存量 |
| 现金流量表 Cash Flow Statement | 现金**进没进兜** | 收付实现制 | 流量 |

行业里的一句话：**"利润是观点，现金是事实。"** 利润可以由会计政策塑造，现金很难造假——这就是三表并读的意义。

### 3.2 利润表的瀑布（投行常用口径）

收入 → 毛利（-营业成本）→ EBITDA（-销售/管理费用、税金及附加，未扣折旧摊销）→ EBIT（-折旧摊销）→ 净利润（-利息、税）。

- **EBITDA** = 息税折旧摊销前利润：剔除资本结构和会计政策差异，是 `EV/EBITDA` 乘数的分母，重资产行业 Comparables 的标配。
- 中国语境注意**"扣非净利润"**（扣除非经常性损益）：证监会口径，看主营业务真实盈利能力。

### 3.3 三表勾稽关系（建模的心脏，必背）

1. 利润表的**净利润** →（间接法）现金流量表的起点，同时进入资产负债表的**留存收益**。
2. 现金流量表的**期末现金** = 资产负债表的**货币资金**。
3. 资产负债表上的折旧摊销 → 利润表里的费用 → 现金流量表里加回来（因为折旧不花现金）。
4. 资产 = 负债 + 所有者权益，永远平衡——建模时三表不平，99% 是上面 1-3 条链条断了。

所谓"三表模型"，就是把这套勾稽关系做成 Excel 联动：改一个假设（比如应收账款周转天数），三张表全部自动联动。

### 3.4 投行视角重点科目

- **应收账款 + 存货增速 vs 收入增速**：收入质量探测器——应收和存货比收入涨得快，警惕压货/放宽信用冲收入。
- **商誉**：并购溢价留下的科目，被收购方业绩不达预期就减值，A股著名的"商誉爆雷"就来自这里。
- **金融负债 vs 经营负债**：算企业价值 EV 时只有金融负债算进去，应付账款这种经营负债不算——后面块4算 EV 会直接用到。
- **少数股东权益**：合并报表里不属于母公司的利润/净资产，归母口径要剔除。

### 3.5 学习建议

- 不用先啃会计教材，重点是**勾稽不是记账**：找一家熟悉的公司（如贵州茅台）年报，把三张表翻出来，手工完成"净利润→留存收益""期末现金→货币资金"两条追踪，比读十章书有用。
- 之后块 4-6 的估值方法全部踩在这些概念上。

## 4. 估值总览 + 相对估值（块4）

### 4.1 估值方法地图（投行估值就这两大家族 + 两个特例）

- **相对估值**：可比公司法（Trading Comps）、可比交易法（Precedent Transactions）——"别人值多少钱"
- **绝对估值**：DCF 现金流折现——"它自己未来能产多少钱"（块5 详解）
- **两个特例**：LBO（PE 收购视角，块6）、SOTP 分部估值（多元化集团拆开算）

投行实际操作是**多法并用取区间**（Football Field 足球场图：横轴是估值区间，每根竖条是一种方法的结果，最后圈出交叉重合区域作为"合理估值区间"）。没有唯一正确的估值，只有可辩护的区间。

### 4.2 企业价值 EV：先统一口径

**EV（Enterprise Value）= 股权价值 + 有息负债 + 少数股东权益 + 优先股 − 现金及等价物**

- 股权价值（Equity Value）= 股价 × 总股本，是"股东的份额"
- EV 是"整个企业的价格"，因为买家除了买股权还要承接债务（减掉现金是因为现金到手可以还债）
- **口径匹配原则**：EV 配 EBITDA/EBIT/Sales（对应全部出资人的收益），股权价值配净利润/净资产（只属于股东）。`EV/净利润` 或 `P/EBITDA` 是常见的口径错配错误。

### 4.3 可比公司法 Trading Comps 操作步骤

1. **选可比组**：同行业 + 相近规模 + 相近商业模式 + 相近成长阶段。行业格局决定乘数高低，不在一个赛道的数据是噪音。
2. **统一财务口径**：TTM（滚动12个月）与 NTM（未来12个月）分开列；剔除一次性损益。
3. **算乘数**：EV/EBITDA、P/E、P/B、P/S、EV/Sales，看分布（中位数比均值抗离群值）。
4. **套用**：目标公司指标 × 可比组中位数乘数 ± 溢价/折价调整（规模、流动性、成长性）。

### 4.4 乘数体系速查

| 乘数 | 适用 | 局限 |
|---|---|---|
| P/E 市盈率 | 盈利稳定的成熟公司 | 亏损/周期顶底时失真；受资本结构影响 |
| EV/EBITDA | 重资产、不同杠杆率公司之间比较 | EBITDA 高估"可分配现金"（没扣 CapEx） |
| P/B 市净率 | 银行、保险等金融机构首选 | 轻资产公司账面净资产无意义 |
| P/S 市销率 | 亏损期高成长（SaaS） | 忽视盈利质量/毛利差异 |
| PEG | 成长股（P/E ÷ 增速%） | 增速外推不可靠 |

### 4.5 可比交易法 Precedent Transactions

用历史并购交易的成交乘数定价。与 Trading Comps 的关键区别：**包含控制权溢价**（买 control 要多付钱，A股叫"收购溢价"，美股历史均值约 20-40%）——所以可比交易估值通常系统性高于可比公司估值。陷阱：交易时点的市场周期、协同效应假设、买卖双方的特殊动机都会污染乘数。

### 4.6 相对估值的根本局限

乘数定价的本质是"市场对这批公司定错了也不会太错"，**它回答不了"这个市场整体是不是错的"**——2000 年互联网泡沫里所有可比公司的 P/S 都高得离谱，用相对估值只会把泡沫标准化。这正是需要 DCF（块5）和巴菲特"买公司"思维（块8）的原因。

## 5. DCF 现金流折现（块5）

### 5.1 一句话原理

**企业的价值 = 未来所有自由现金流的现值之和。** 货币有时间价值（今天的一块钱 > 明年的一块钱），所以把未来的钱按折现率拉回今天。

### 5.2 标准流程（五步）

1. **预测显性期自由现金流**（通常 5-10 年）：
   `FCFF = EBIT × (1−税率) + 折旧摊销 − 资本支出 CapEx − 净营运资本增加 ΔNWC`
   - FCFF（企业自由现金流）属于全部出资人，配 WACC 折现 → 得 EV
   - FCFE（股权自由现金流）只属于股东，配股权成本折现 → 直接得股权价值
2. **算折现率 WACC（加权平均资本成本）**：
   `WACC = E/(D+E) × Re + D/(D+E) × Rd × (1−税率)`
   - Re 用 **CAPM**：`Re = 无风险利率 + β × 股权风险溢价`（β 衡量股票相对大盘的波动敏感度）
   - 债务成本可以税前抵扣，所以乘 (1−税率)——这就是"税盾"
3. **算终值 Terminal Value**（两种方法）：
   - 永续增长法（Gordon）：`TV = FCFF_最终年 × (1+g) / (WACC − g)`，g 通常取 2-3%（≈长期通胀），必须 WACC > g
   - 退出乘数法：`TV = FCFF_最终年 × 退出EV/EBITDA`
4. **折现回来**：`企业价值 = Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^终期`
   - 中期惯例：用"中间年折现因子"处理估值基准日问题
5. **EV → 股权价值 → 每股价值**：`股权价值 = EV − 净债务`，除以稀释后股本，与现价比较。

### 5.3 必须知道的三件事（DCF 的软肋）

- **敏感性恐怖平衡**：终值通常占总价值的 60-80%，而它取决于 g 和 WACC 这两个最不确定的参数。所以 DCF 一定要配敏感性分析表（g × WACC 的矩阵），输出一个区间而不是一个数。
- **垃圾进垃圾出**：DCF 的精度来自输入假设（收入增速、利润率、CapEx），模型工整≠结论正确。投行话术："模型没问题，假设可以聊"。
- **DCF 和相对估值是互相校验的**：DCF 给出"内在价值锚"，Comps 给出"市场锚"，两者背离本身就是信息（背离大 = 市场与你的假设有分歧，先检讨自己）。

### 5.4 动手路径

- 用本机金融技能可以直接搭：给我一家上市公司代码，就能生成三表模型 + DCF + 敏感性表（write-research 技能链）。
- 手工练习：Excel 里拿长江电力这类现金流稳定的公司练手——水电的现金流形态是教科书级的 DCF 素材。

## 6. LBO 杠杆收购 + M&A 增厚摊薄（块6）

### 6.1 LBO：用借来的钱买公司

**LBO（Leveraged Buyout）**：PE 基金用大部分债务 + 少部分自有资金买下公司，用公司自身的现金流还债，3-7 年后卖出退出，赚**内部收益率 IRR**。

收益四大来源（IRR 归因，面试必考）：
1. **EBITDA 增长**：收入增长 + 利润率提升（经营改善）
2. **去杠杆**：现金流还债 → 债务减少 → 股权占比被动上升
3. **退出乘数扩张**：卖的时候比买的时候倍数高（最难预测，最不可靠）
4. **低买**：入场价格本身便宜

什么样的公司是好的 LBO 标的：**现金流稳定可预测**（还得起债）、**资本开支轻**（不用持续大投入）、**当前杠杆低**（还有加债空间）、**有可剥离资产**。这就是为什么消费、软件、基础设施是 PE 最爱，而强周期重资产公司很难做 LBO。

LBO 模型的三条硬约束：债务容量（银行/债券市场愿意借多少，由 EBITDA 倍数定）、最低现金余额、偿还顺序（先高息后低息）。买价倒算：给定目标 IRR（通常 20%+），反推最高能出多少钱——这就是 PE 的"出价纪律"。

### 6.2 M&A 并购：投行最赚钱的脑力生意

**财务顾问流程**（卖方视角）：pitch 路演 → 签 NDA → 发 Teaser 摘要 → 有意向方签保密协议 → 发 CIM 备忘录 → 收首轮意向报价 → 数据室尽调 → 二轮报价 → 谈判 SPA → 签约 → 交割。投行在每个环节收顾问费，大单顾问费可达千万美元级。

**增厚/摊薄分析（Accretion/Dilution）**——并购定价的收口问题：
- 问一句话：**收购后买家的 EPS 是升（增厚）还是降（摊薄）？**
- 全现金收购：EPS 增厚条件 ≈ 目标公司税后收益 > 融资资金的税后成本（借债利率 × (1−税率)，或失去的现金利息）
- 换股收购：增厚条件 ≈ 目标 P/E < 买家 P/E（用便宜的股票买贵的盈利，EPS 自然增厚）
- 完整分析要加入：商誉与无形资产摊销、协同效应（收入协同/成本协同，通常成本协同更可信）、交易费用
- 血泪教训：增厚的并购不一定是好并购（EPS 增厚可以纯靠低息借款堆出来），摊薄的并购也可能是好并购（买了高成长）——**EPS 是算术，价值是判断**。

### 6.3 并购协同效应的纪律

协同效应估值必须回答三个问题：是什么（成本协同砍重复部门 vs 收入协同交叉销售）、多久实现（通常 2-3 年爬坡）、实现成本多少（重组费用、留才奖金）。华尔街统计：绝大多数并购未达预告的协同目标——所以审慎模型会把协同打个折再算进价格。

## 7. 中国券商投行生态（块7）

### 7.1 中国"投行"= 券商投行部，业务与外资投行的对应关系

| 中国业务 | 对应外资投行条线 | 说明 |
|---|---|---|
| 股权融资（IPO/定增/配股/可转债） | ECM | 保荐 + 承销 |
| 债券承销（公司债/企业债/金融债） | DCM | 银行间与交易所两个市场 |
| 并购财务顾问 | M&A Advisory | 重组、借壳、跨境并购 |
| 新三板/北交所 | — | 阶梯式多层次资本市场 |

注意：中国没有独立的"投资银行"牌照——投行业务是券商（证券公司）的一个部门；商业银行的投行部主要做债券承销与银团贷款，业务范围不同。

### 7.2 注册制下的核心制度（必须懂的几个词）

- **全面注册制**（2023年起全市场推行）：证监会管"门槛合规"，交易所审核问询，信息披露为中心——投行的工作重心从"搞定审批"变成"把公司讲清楚 + 真实准确完整"。
- **保荐代表人**（"保代"）：签字责任人，一个项目两名保代签字背书，出问题终身追责。曾经几十万到百万元级年薪的"金领资格"，考试在协会，项目经验才是真正的门槛。
- **三道防线**：项目组 → 质控 → 内核合规。底稿（工作底稿）是监管检查的生命线——"底稿不出来，项目就是裸奔"。
- **现场检查/现场督导**：监管直接进场抽查，撤否率高企的年份，"一查就撤"成为行业现象。

### 7.3 2025 年的最新格局（联网核实）

- A 股在审项目头部集中：**国泰海通**（国泰君安+海通合并后）第一，**中信证券**、**中信建投**随后；"三中一华"（中信/中金/中信建投/华泰）+ 新合并巨头占大头。
- **2025 年是港股 IPO 大年**：全年新上市公司 117 家，上半年募资近 1000 亿港元，为近十年最忙窗口；**中金公司**以 46 单参与居首。中资投行包揽港股保荐前四。
- 趋势判断：注册制 + 头部集中 = 马太效应加剧；A 股节奏受调节，港股成为中资投行的增量主战场；并购重组在"并购六条"后成为政策鼓励的新增长点。

### 7.4 职业路径速览

分析师（2-3 年，做底稿/尽调/写材料）→ 项目经理/高级经理（现场负责人）→ 保代/业务董事（签字）→ MD（承揽）。承揽（拉项目）是天花板，承做（干项目）是基本功。对应外资：Analyst → Associate → VP → ED → MD。

## 8. 价值投资源流：格雷厄姆 → 费雪 → 巴菲特 → 芒格（块8）

> 价值投资的谱系要当一条进化链读：格雷厄姆发明方法，费雪提供另一半视角，巴菲特把两者融合，芒格把质量维度推向极致。

### 8.1 格雷厄姆（Benjamin Graham）——价值投资之父

- 代表作：《证券分析》（1934，与多德合著）、《聪明的投资者》（1949）
- 三个原创概念：**市场先生**（Mr. Market：市场是情绪化的报价机器，你可以利用它而不是被它牵着走）、**安全边际**（Margin of Safety：买入价要显著低于内在价值，留足犯错空间）、**股票=企业部分所有权**（当时革命性的观念）
- 方法时代烙印：捡烟蒂（买低于净流动资产的股票）。1929 年大崩盘后写成的书，防身优先于进攻。
- 直接传人：巴菲特、施洛斯（Walter Schloss，纯烟蒂法也年化 20%+ 四十年）

### 8.2 费雪（Philip Fisher）——成长股投资的另一源头

- 代表作：《怎样选择成长股》（1958）
- **15 要点**：看公司的销售成长潜力、利润率、研发、管理层深度……
- **闲聊法（Scuttlebutt）**：去和客户、对手、前员工、供应商聊——产业调研的鼻祖
- 核心主张：集中持有极少数真正伟大的成长公司，长期不卖。巴菲特自称"85% 格雷厄姆 + 15% 费雪"，费雪那 15% 后来实际上变成了主导。

### 8.3 巴菲特（Warren Buffett）——集大成者

- 2025 年 5 月股东大会宣布年底卸任 CEO（1965 年执掌伯克希尔 60 年），Greg Abel（格雷格·阿贝尔）接任 CEO，巴菲特留任董事长。伯克希尔股价 60 年年化约 20%，复利故事本身就是教材。
- 核心思想（读**历年致股东信**，网络免费全文，这是他唯一系统的"著作"）：
  1. **买股票就是买公司**：内在价值 = 企业存续期内自由现金流的折现——和块 5 的 DCF 是同一个思想
  2. **护城河**：品牌、成本优势、网络效应、转换成本、特许经营权——护城河决定长期超额利润能否持续
  3. **能力圈**：重要的不是圈子多大，而是知道边界在哪。"我们对蛋黄派不理解，所以我们不碰。"（看不懂就放过，错过了不是错误）
  4. 从"烟蒂"到"伟大公司合理价格"的转变（喜诗糖果案例：1972 年用 2500 万买下，累计贡献超百亿利润——芒格推动的转折点）
  5. **"别人贪婪时恐惧，别人恐惧时贪婪"**：市场先生的反向利用
  6. 长坡厚雪：人生像滚雪球，重要的是找到很湿的雪和很长的坡

### 8.4 芒格（Charlie Munger，1924-2023）——理性主义的极致

- 代表作：《穷查理宝典》（Poor Charlie's Almanack）
- **多元思维模型**：只用金融学看世界必然失真，要把数学、物理、生物、心理、经济等 ~100 个学科的硬核模型装进格栅（latticework），交叉验证着用
- **逆向思维**："反过来想，总是反过来想"——想成功先研究怎么会失败，然后别做那些事
- **lollapalooza 效应**：多种倾向（激励机制、从众、承诺一致性……）叠加在一起会产生巨大的非理性——人为什么会做蠢事
- 经典格言："如果我知道我会死在哪里，我就永远不去那里"；"用合理的价格买伟大的公司，胜过用便宜的价格买平庸的公司"

### 8.5 这条线的现实意义

巴菲特-芒格体系与块 4-6 的投行估值体系**用的是同一套底层语言**（现金流、折现、护城河≈超额收益持续性），差别只在持有期限和目的：投行算完价格就卖服务，价值投资者算完价格就买下等十年。两边一起学，估值部分学一遍就够。

## 9. 实用派与宏观派：林奇/博格 + 达利欧/索罗斯/马克斯（块9）

### 9.1 彼得·林奇（Peter Lynch）——业余投资者最友好的大师

- 代表作：《彼得·林奇的成功投资》（One Up on Wall Street）、《战胜华尔街》
- 执掌富达麦哲伦基金 13 年年化 29%，退休后写书教散户
- **六类公司分类法**：缓慢增长型、稳定增长型、快速增长型、周期型、困境反转型、隐蔽资产型——先归类，再决定怎么跟踪、什么时候卖
- **PEG**：P/E ÷ 盈利增速，找"增长还没被定价"的公司（PEG<1 有吸引力，注意是经验法则不是定律）
- **身边找牛股**：从日常生活中发现好生意（他因太太和家人喜欢而发现 L'eggs 丝袜、Dunkin' Donuts）——但要区分"产品受欢迎"和"股票值得买"（还要看估值和扩张空间）
- 实用格言："长期而言，股市的收益取决于公司盈利的增长"；"卖出赢家换进输家是拔掉鲜花浇灌杂草"

### 9.2 约翰·博格（John Bogle）——指数基金之父，与上面所有人"对着干"

- 先锋基金创始人。核心论点：**绝大多数主动基金长期跑不赢指数，原因是成本**——"成本加害假设"（Cost Matters Hypothesis）
- 铁三角：低成本 + 广分散 + 长持有。复利的敌人不是波动，是费用和摩擦。
- 代表作：《共同基金常识》（Common Sense on Mutual Funds）
- 与巴菲特关系微妙而有趣：巴菲特认可博格（立遗嘱指示家人买指数基金），但自己也做主动投资——他赢在信息与 temperament，散户往往两者都没有。**对普通人的默认答案就是博格的答案。**

### 9.3 瑞·达利欧（Ray Dalio）——把宏观做成机器

- 桥水基金创始人；代表作：《原则》（Principles）
- **极度求真、极度透明**：公司内部一切讨论记录、缺点公开——用系统化规则代替拍脑袋（他发明了"想法结晶"打分系统）
- **痛苦 + 反思 = 进步**：把错误当成生产资料
- **债务大周期**：经济 = 无数个信贷的总和；信贷扩张→繁荣→顶点→去杠杆→衰退，短周期（5-8年）嵌套长周期（75-100年）。2025 年新书**《国家如何破产》（How Countries Go Broke）**把这套框架对准美国国债：财政赤字货币化、债务货币贬值风险、警告美元相对黄金等硬资产贬值——这是他近年最核心的公开观点。
- 全天候策略/风险平价：按经济状态的四象限（增长/通胀 × 超预期/低于预期）平衡配置风险而非资金

### 9.4 索罗斯（George Soros）——反身性理论

- **反身性（Reflexivity）**： participants' 认知与现实互相塑造——价格上涨改变基本面预期→预期推动更多上涨→泡沫自我强化→直到反身性反转。经典案例：1992 年狙击英镑（"击垮英格兰银行的人"，一天赚 10 亿美金）
- 与有效市场假说直接对立：市场不是总趋于均衡，认知偏差可以被自我实现
- 对你的意义：理解"趋势为什么能自我强化"，是识别泡沫和抱团的关键视角

### 9.5 霍华德·马克斯（Howard Marks）——周期与风险

- 橡树资本联合创始人；代表作：《投资最重要的事》；备忘录免费公开（Oaktree 官网，巴菲特说"每封邮件必读"）
- **第二层思维**：第一层："这是家好公司，买。"第二层："这是家好公司，但人人都知道且价格已经反映，卖。"——超额收益来自比共识想得更深
- **市场钟摆**：在贪婪与恐惧、乐观与悲观之间摆动，极少停在中间——判断"钟摆现在的位置"比预测未来更重要
- **风险≠波动**：真正的风险是永久性损失概率；"最危险的时刻是看起来最安全的时候"（低波动让人加杠杆）
- 核心句："你不可能在和别人做着相同的事情时，期待获得超额收益。"

## 10. 中文圈大V：段永平/张磊/邱国鹭/但斌/李录/林园（块10）

### 10.1 段永平（雪球 ID"大道无形我有型"）——中式价值投资影响力第一人

小霸王/步步高创始人，OPPO/vivo 的幕后教父，网易丁磊的老师，拼多多黄峥的导师。2001 年移居美国转做投资：0.8 美元重仓网易（涨百倍）、2011 年买苹果、后来买茅台。

他的投资框架（反复在雪球问答里讲，就这几条，全都在）：
1. **买股票就是买公司，就是买公司未来现金流的折现**——和巴菲特/块 5 的 DCF 完全同构，但他强调这是"唯一"的估值方式
2. **不懂不做**（能力圈）："敢重仓的唯一理由是真懂"——他自己重仓过的公司一只手数得过来，拿的都是 5 年起步
3. **Stop Doing List**：不为清单——不做空、不借钱（margin）、不做不懂的东西。他说"我也不知道哪天会有大机会，但只要不犯错，机会来了我还活着"
4. **本分 + 平常心**：做生意如此，投资亦然；"快就是慢，慢就是快"
5. 对"便宜"的定义：便宜是相对于内在价值，不是相对于上次股价

### 10.2 张磊（高瓴资本）——机构化长期主义

- 代表作：《价值》（2020）："做时间的朋友""长期结构性价值投资""疯狂创造价值的企业家精神"
- 高瓴从耶鲁捐赠基金的 2000 万美元起步（导师是耶鲁捐赠基金掌门史文森——机构投资界的"格雷厄姆"），做成亚洲最大资管平台之一；风格是重仓 + 深度介入经营（百丽私有化改造、格力混改）
- **需要辩证看**：2026 年媒体的"高瓴盈亏实录"显示其在格力、隆基等标的上出现过百亿级浮亏——长期主义不等于必然正确，机构同样有周期错判。学他的方法论框架，别神化具体战绩。

### 10.3 邱国鹭（高毅资产董事长）——中式表述最清晰的框架

- 代表作：《投资中最简单的事》——中文投资书里可读性最好的一本，入门首选
- 核心句："**便宜的好公司**"四个字拆开：便宜（估值）+ 好公司（品质），加上"行业格局"共同构成三维分析
- 名句："**数月亮不数星星**"——买寡头格局确立的行业（月亮），不赌一地鸡毛的红海（星星）；"胜而后战"：等竞争格局打完再进场
- 对品质的三问：是不是好生意（定价权！）、是不是好公司（管理层/企业文化）、是不是好价格

### 10.4 但斌（东方港湾）——"时间的玫瑰"

- 代表作：《时间的玫瑰》：与伟大企业共成长，长期聚焦"改变世界的公司"
- 实操记录两极：重仓白酒（茅台）成名；2022 年净值大幅回撤引发"价值投资是否失效"大讨论；2023 年后转向美股 AI 巨头又大赚——风格从"纯粹的巴菲特式"演化成"聚焦最前沿的集中投资"
- 学习点：他的经历恰好证明（块 11 要讲的）"同一个大V，不同阶段表现可能完全相反，语境很重要"

### 10.5 李录——喜马拉雅资本，芒格家族的资产管理人

- 代表作：《文明、现代化、价值投资与中国》
- 把价值投资放进文明史的框架：现代化 = 科技 + 自由市场结合的"1+1>4"，价值投资成立的前提是市场经济持续创造价值
- 总结价值投资四个支柱（最简明版本）：①股票=公司部分所有权 ②市场先生为你服务而非指挥你 ③安全边际 ④能力圈
- 查理·芒格家族把钱交给他管理几十年——"师承"含金量的背书

### 10.6 林园——草根派代表

- 代表作：《林园炒股秘籍》。"**嘴巴生意**"逻辑：成瘾性消费品（白酒、医药）现金流最好；高度集中持股

## 11. 如何批判性地使用大V言论（块11）

> 学理论是为了建立自己的判断框架，不是为了找到"跟着买"的对象。这一块是安全带。

### 11.1 五个系统性偏差

1. **幸存者偏差**：你看到的大V都是活下来的。同样逻辑亏光的人不会开直播。评估一个方法论，要看它的完整分母，而不是成功样本。
2. **立场偏差**：大V的持仓就是他的立场。喊多的人往往已经重仓（他的发言本身就在影响价格）；收费荐股、带货课程、私募募资路演，天然有利益动机。
3. **事后归因**：很多"理论"是结果出来之后反向编的故事。真正可检验的理论要能**事前**给出可证伪的判断（块的笔记里达利欧、马克斯的做法就比"感悟式鸡汤"可检验性高）。
4. **语境漂移**：同一句话在牛市和熊市、小资金和大资金语境下含义完全不同。"长期持有"对财务自由的人是自然状态，对年轻人可能是没有研究能力时的借口。
5. **知行分离**：口述理论和真实持仓可能不一致。看一个人的**操作记录**（基金季报、年报、实盘披露）比看他**说什么**更可靠。

### 11.2 消费大V内容的三层过滤

- **第一层（合规）**：无证券投资顾问牌照的人在社交媒体荐股并收费，在中国属于违法行为；任何"带你买""进群""加微信"都是红灯。
- **第二层（信息）**：把大V的话降级为"线索"而非"结论"——他说某行业格局好，你去读行业研报、财报验证，走自己的证据链（就像块 3 的应收账款探测器）。
- **第三层（框架）**：只吸收**可迁移的方法论**（安全边际、能力圈、第二层思维、周期位置），不模仿**不可迁移的具体操作**（他的标的、仓位、加杠杆方式——他的资金期限和你的完全不同）。

### 11.3 一手材料清单（替代二手解读）

- 巴菲特：历年**致股东信**（伯克希尔官网免费）——所有二手"巴菲特理论"的源头
- 霍华德·马克斯：Oaktree **备忘录**（官网免费）
- 达利欧：《原则》《国家如何破产》原书（X/公众号上的摘要大量失真）
- 段永平：雪球问答原帖（"大道无形我有型"），只看原话，不看"解读段永平"的营销号
- 上市公司：**年报原文**（巨潮资讯网 cninfo）——一切观点的最终裁判

### 11.4 底线提醒

本笔记是知识整理，不构成任何投资建议；真实资金操作前，先想清楚自己的资金期限、风险承受力和"如果全亏了会怎样"。

## 13. Git 深水区：内部机制与高级操作（块13）

### 13.1 对象存储：Git 为什么"改不坏"

- 所有对象存在 `.git/objects/`，用 **SHA-1 内容寻址**：内容变了哈希必变——所以提交历史天然防篡改（改历史 = 产生新哈希链，这就是为什么 rebase 是"改写"而 revert 是"追加"）。
- 松散对象会被 `git gc` 打成 **packfile**（增量压缩）。日常不用管，但"仓库为什么突然变小了"的答案就是它。
- 新仓库可以选 SHA-256（`git init --object-format=sha256`），旧生态大多还是 SHA-1。
- **ref 的本质**：`refs/heads/`（本地分支）、`refs/remotes/`（远程分支的本地缓存）、`HEAD` 文件。所谓"删除分支"就是删一个 41 字节文件，提交对象会在 gc 时才真正清理——这解释了为什么 `reflog` 能救人。

### 13.2 高级工具与典型场景

| 工具 | 场景 |
|---|---|
| `git worktree` | 一个仓库多工作树：一边在 `main` 修线上 bug，一边在另一个目录开发 feature，互不干扰 |
| `git submodule` / `subtree` | 仓库嵌套仓库。submodule 是"指针"（容易忘更新，团队里坑多），subtree 是"拷贝"（历史混在一起）；小团队建议先 subtree |
| `git hook`（pre-commit / commit-msg / pre-push） | 提交前自动跑 lint/测试、校验 commit message。用 husky / pre-commit 框架把 hooks 纳入版本管理，团队才能统一 |
| Git LFS | 大文件（模型、视频、数据集）单独存指针，否则仓库膨胀到无法 clone |
| `git bisect` | 二分定位 bug：`bisect start → bad → good` 后 Git 自动在中间提交间切换，跑测试标 bad/good，log(n) 次锁定坏提交。可写脚本自动化 `bisect run` |

### 13.3 心法

Git 的一切恐惧来自"怕弄坏"。事实：**已提交的对象几乎不可能丢**（reflog + gc 保留期默认 90 天）。所以正确的练习方式是开一个垃圾仓库，故意把 rebase/reset/ cherry-pick 弄乱，再用 reflog 修好——练 3 次就不怕了。

## 14. 财报进阶：盈利质量与造假信号（块14）

### 14.1 杜邦分析：ROE 三分解

`ROE = 净利率 × 资产周转率 × 权益乘数`——三种完全不同的好生意：
- **茅台型**（高净利率，~50%）：品牌定价权，躺着赚钱
- **沃尔玛型**（低净利率 + 高周转）：靠效率和规模
- **银行型**（中净利率 + 杠杆）：赚资金成本差，怕坏账

分析公司先问：它的 ROE 靠哪一项？可持续吗？（长期 ROE>15% 且主要靠前两项，通常是好生意。）

### 14.2 现金流质量铁律

**经营现金流净额 ÷ 净利润 ≥ 1** 是健康线（利润都变成了真钱）。连续多年 < 0.7：要么利润有水分，要么全是应收账款——块 3 的应收探测器在这里闭环。

### 14.3 财务造假信号清单（任何两条以上亮红灯就要查个底朝天）

1. 应收账款/存货增速长期远超收入增速
2. 毛利率显著高于同行且无合理解释（同行都在 30%，你说 60%）
3. **存贷双高**：账上几百亿现金，同时借几十亿有息负债（钱多为什么还借钱？）——康得新 122 亿"存款"其实不存在
4. 在建工程常年不转固（折旧游戏）、无形资产/商誉占比畸高
5. 关联交易占比高、大客户神秘（瑞幸：虚构订单，关联方充量）
6. 审计意见非标、频繁更换会计师事务所、CFO 频繁离职
7. 大股东高比例质押 + 频繁减持

经典案例：康美药业（虚增货币资金近 900 亿）、瑞幸咖啡（虚构交易 22 亿，浑水匿名做空报告揭开）、康得新（存贷双高教科书）。读一份做空报告（浑水/香橼）是最好的"排雷课"。

## 15. 行为金融：认知偏差自查表与纪律（块15）

### 15.1 理论地基

- 卡尼曼《思考，快与慢》：系统 1（快直觉）/系统 2（慢理性）；**前景理论**——损失厌恶（亏 100 元的痛 ≈ 赚 200 元的爽）、参照点依赖（人的决策围绕"锚"而不是绝对值）
- 塔勒布《黑天鹅》《反脆弱》：极端事件比想象常见；**杠铃策略**——极端保守 + 小仓位极端激进，避免中间地带；投资要选"凸性"机会（下有底、上不封顶）

### 15.2 偏差自查表（每次下单前过一遍）

| 偏差 | 表现 | 对策 |
|---|---|---|
| 损失厌恶 | 亏损股死扛不卖，"没卖就不算亏" | 事前写下卖出条件，触发即执行 |
| 锚定 | 被自己的成本价锚定（成本 10 元跌到 5 元觉得"便宜"） | 只问现在的价格 vs 价值，成本价与你无关 |
| 确认偏误 | 买入后只看利好、拉黑看空的人 | 强制读一篇对方的反方观点 |
| 从众 | 涨了才研究，追热点 | 建立自己的清单，热的时候看冷的数据 |
| 过度自信 | 加杠杆、满仓单票 | 仓位上限（单票 ≤15-20%）、不借钱（段永平 Stop Doing List） |
| 处置效应 | 卖盈保亏（拿不住赢家，抱死输家） | 按"买入逻辑是否还在"决策，不按浮盈浮亏 |

### 15.3 工程师式对策：把投资流程代码化

- **投资决策日志**：每笔操作前写 100 字（买入理由、预期、卖出条件、如果错了是因为什么）——相当于给自己 code review；一年后回看，这是进步最快的方式
- 定期定额 + 定期再平衡：用规则代替情绪
- 凯利公式 `f = (bp − q)/b` 告诉你最优下注比例，但参数估计误差大——实践中用**半凯利或更低**，或者干脆用"等权 + 上限"这种笨办法

## 16. 宏观最小必要知识（块16）

> 不用成为宏观经济学家，只需要一套"当前钟摆在哪里"的仪表盘。

### 16.1 三个变量决定估值中枢

1. **增长**：GDP、PMI（50 荣枯线）、社零/出口——决定分盈利 E
2. **通胀**：CPI/PPI——决定央行松紧
3. **流动性**：利率（十年国债收益率）、社融增速、M1-M2 剪刀差——决定分母贴现率 r 和风险偏好

DCF 视角一句话打通：**股价 = E/r 的游戏**。利率上行 → r 上行 → 高久期资产（成长股、长久期债券）估值收缩最狠；这就是"美联储放水利好科技股"的全部机制。

### 16.2 钟摆定位的免费仪表盘（全部公开数据）

- **股权风险溢价 ERP** = 1/沪深300市盈率 − 十年国债收益率：历史高位（>6%）通常是底部区，低位是顶部区
- 指数估值分位（PE/PB 十年百分位）——贵不贵看分位，不看绝对值
- 社融存量增速：信用扩张/收缩的领先指标
- M1-M2 剪刀差：资金活化程度（企业愿不愿意把钱拿出来干活）

### 16.3 与大师框架的合流

达利欧告诉你周期的形状（信贷扩张→顶点→去杠杆），马克斯告诉你怎么判断位置（钟摆），格雷厄姆/巴菲特告诉你位置极端时该做什么（贪婪/恐惧倒着来）。宏观不预测点位，只回答一个二元问题：**现在是危险的地方还是机会的地方？**

## 17. DCF 手搭操作卡（块17）

> 目标：两周内在 Excel 里从零搭一份能跑的 DCF。先用示例假设练手，跑通后换成真实数据。所有数字是**教学示例**，不是预测。

### 17.1 表结构（自上而下五段）

1. **假设区（黄色底）**：收入增速（第1年 10%，线性递减至终期 3%）、EBITDA 率 30%、D&A 占收入 5%、税率 25%、CapEx 占收入 6%、ΔNWC 占收入增量 10%
2. **FCFF 区**：行依次 = 收入 → EBITDA → D&A → EBIT → 税 → NOPAT → 加回 D&A → 减 CapEx → 减 ΔNWC → **FCFF**
3. **WACC 区**：无风险利率（十年国债 ~2%）+ β（1.0）× ERP（6.5%）= Re ≈ 8.5%；Rd = 4%，税盾后 3%；目标 D/(D+E) = 20% → **WACC ≈ 7.4%**
4. **终值区**：`TV = FCFF_第10年 × (1+2.5%) / (WACC − 2.5%)`
5. **汇总区**：`EV = Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^10` → 减净债务 → 股权价值 → ÷股本 = 每股内在价值

### 17.2 必做的三个检查

- **敏感性双变量表**：Excel "数据 → 模拟分析 → 模拟运算表"，行放 WACC（±1%）、列放永续 g（±0.5%），看每股价值区间——这就是给"模型不确定性"定价
- **终值占比**：TV 现值 ÷ EV 落在 60-80% 属正常，但你要能解释 g 和退出乘数为什么这么取
- **三表联动版**：第二遍搭的时候把三表勾稽（块 3）做进去，改一个假设全表联动——这才是"三表模型"

### 17.3 验收标准

搭完后能回答：为什么 EBITDA ≠ 现金？为什么 CapEx 和 ΔNWC 是减项？为什么 WACC 里债务成本要乘 (1−税率)？g 为什么不能超过 WACC？——四个问题都答得出，DCF 就算真学会了。

## 18. 科技/创业圈大V：Paul Graham、Naval、Thiel（块18）

> "大V的理论"不只存在于金融圈。对计算机专业的你，这三位的影响可能更直接。

### 18.1 Paul Graham——程序员写作者的天花板

- Y Combinator 创始人，essays（paulgraham.com，全免费）是互联网写作的标杆
- 核心思想："**Make something people want**"（做别人想要的东西）；"**Do things that don't scale**"（早期别怕笨办法，先验证需求）；创业初期要的是少量用户**深度热爱**，而不是很多用户**轻度喜欢**
- 《Hackers and Painters》：编程是创作不是工程，黑客与画家是同一类人
- 对你的启示：**写作是程序员的隐藏杠杆**——他用写作建立了 YC 的品牌。从今天起把学习笔记公开（GitHub Pages，第 3 周任务），就是最便宜的复利

### 18.2 Naval Ravikant——《纳瓦尔宝典》

- AngelList 创始人；书是推文和播客的合集（官方免费电子版存在）
- 核心：**"用杠杆放大你的判断力"**。三种杠杆：劳动力（要管人，最古老）、资本（要人给钱）、**代码与媒体（ permissionless leverage，无需许可——写出来的代码/内容 24 小时替你工作，边际成本为零）**。程序员天然持有第三种
- **特定知识（specific knowledge）**：追求那些"无法通过培训获得"的知识——你的兴趣+天赋+时代需求的交集
- "把自己产品化"：产品化 = 规模化复制自己；"财富是睡觉时也在赚钱的资产，金钱只是转移财富的工具"

### 18.3 Peter Thiel——《从0到1》

- PayPal 创始人、Founders Fund 创始人
- **垄断 vs 竞争**："竞争是失败者的游戏"——企业要做的是建立垄断（网络效应、规模、品牌、专利），"从0到1"是做全新的事，"从1到n"只是复制
- **幂律**：风险投资的收益来自极少数大赢家——所以 VC 挑项目极度挑剔；这同样适用于你个人精力的分配（少数值得 All-in 的事）
- **秘密理论**：伟大的公司建立在一个"你相信但大多数人还不认同"的秘密上——面试题"有什么重要的事情你不同意主流看法"值得每半年问自己一次

### 18.4 与前 17 块的合流

Graham/Naval/Thiel 的杠杆理论与 Git/开源生态直接衔接：**代码是无需许可的杠杆，开源是你的简历，写作是你的放大器**。学生期最可执行的路径就是块 12 四周计划里那条：仓库 + PR + 公开笔记——它同时是工程训练、金融素养的记录、和 Naval 式的个人产品化起点。

## 19. Git 生态前沿：新工具、新威胁、新玩法（块19）

### 19.1 后 Git 时代：jj 与 Sapling

- **Jujutsu（jj）**：Rust 编写的 Git 兼容 DVCS（GitHub: jj-vcs/jj），设计目标是"吸取 Git 优点、修掉它的坑"——工作副本本身就是一次提交（省掉 staging 区的心智负担）、rebase 不怕冲突堆积。2025 年已基本可用，jj 核心开发者自己用 jj 开发 jj；少量功能（submodule 兼容、部分 tag 操作）仍在补齐。学习意义：**先学精 Git，再玩 jj**——两者仓库互操作，概念可迁移。
- **Sapling**（Meta 开源）：同思路的大规模版本控制，配合 Monorepo 使用。
- **Monorepo 趋势**：Google（Piper）、Meta 都用超大单体仓库，靠工具链（稀疏检出、按目录授权）解决规模问题。了解前沿工具的价值在于理解"Git 不是终点，是当前最优解"。

### 19.2 供应链安全：2025 年起必修的一课

你 `npm install` / `pip install` 的每个包都是一次信任决策。核心防护：
- **提交签名**：`git commit -S`（GPG）或 SSH 签名（`gpg.format ssh`），GitHub 显示 "Verified" 徽章
- **Sigstore**：谷歌主导的**无密钥签名**（用 OIDC 身份签名，证书记录在 Rekor 透明日志，任何人可审计），sigstore-python 已发稳定版，GitHub Actions 官方集成
- **依赖安全**：Dependabot（自动提 PR 修漏洞依赖）、`npm audit`/`pip-audit`、SBOM 物料清单、lockfile 必须入库
- 经典事故类型：typosquatting（仿冒包名）、维护者账号劫持、恶意版本发布

### 19.3 三条实操

1. 给 GitHub 配置 SSH 签名提交（十分钟，贡献从此带 Verified 徽章）。
2. 自己仓库开 Dependabot + 基础 CI。
3. 有余力用 jj 管一个侧项目，反哺对 Git 的理解。

## 21. 三表模型手搭操作卡（块21）

> 块 17 是 DCF，这里是它的上游：三表联动模型。这是投行面试实操题的第一名，也是所有估值模型的母体。

### 21.1 搭建顺序（顺序错了必配不平）

1. **先搭利润表**（单列即可）：收入（增速假设）→ 成本费用 → EBITDA → D&A → EBIT → 利息 → 税 → 净利润
2. **再搭资产负债表骨架**：现金（由现金流量表喂）、应收/存货/应付（按周转天数算，如 `应收 = 收入 × DSO/365`）、固定资产（期初 + CapEx − 折旧）、负债、股本、**留存收益（期初 + 净利润 − 分红）**
3. **最后搭现金流量表**：间接法——净利润 → 加回 D&A → 减营运资本变动（Δ应收+Δ存货−Δ应付）→ 减 CapEx → 加融资流（借款/还债/分红）→ **期末现金**
4. **闭环校验**：期末现金填回资产负债表；用"资产−负债−权益 = 0"做检查单元格，任何输入变化后必须恒为 0

### 21.2 三表模型必查清单（配不平时按此排查，命中率 95%）

- 留存收益有没有滚动（期初 + 本期净利润 − 分红）？
- 折旧：利润表里的数和现金流量表加回的数、和固定资产里扣的数，是**同一个数**吗？
- 利息：有没有用"期初债务余额"算（避免循环引用；进阶用循环迭代）
- 应收/存货/应付的**变动方向**：应收增加 = 现金流出（不是流入！）
- 分红在三个地方出现：利润表不出、现金流量表流出、资产负债表减留存收益——漏一处就差一圈

### 21.3 与 DCF 的衔接

三表模型跑平后，FCFF 直接从模型里取（EBIT×(1−t)+D&A−CapEx−ΔNWC），块 17 的 DCF 就有了真实底稿——这两张操作卡合起来就是一份完整的"个人投行训练营"。

## 22. 行业研究方法论 + 白酒 2025 实战案例（块22）

### 22.1 行业研究五问框架

1. **空间**：市场多大（TAM）、渗透率多高——渗透率 <20% 的成长期 vs >80% 的存量期打法完全不同
2. **格局**：CR5 集中度、竞争要素（价格/品牌/渠道/技术）、五力（供应商/买方/新进入/替代品/内部竞争）——格局决定利润率的可持续性（邱国鹭"数月亮"）
3. **商业模式**：谁付钱、定价权在谁手上、收入是订阅型还是项目制
4. **景气位置**：处在成长/成熟/衰退，以及短周期（库存周期）的位置
5. **政策**：监管变量（集采之于医药、平台监管之于互联网）

### 22.2 三层证据与高频跟踪指标

- **底层数据**：统计局、行业协会、上市公司财报（巨潮资讯网免费）
- **产业链交叉验证**：上游涨价 → 下游毛利率承压，用上下游财报互相打脸
- **高频指标**：每个行业有自己的"体温计"——白酒看**批价**（经销商之间批发成交价），面板看稼动率，锂电看碳酸锂价，地产看二手房成交量。找到高频指标 = 拿到行业的实时心电图。

### 22.3 实战案例：2025 年白酒（联网核实）

2025 年白酒处于**深度调整期、全面进入存量竞争**：飞天茅台批价**跌破 1499 元官方指导价**（经销商综合成本约 1700-1800 元，价格倒挂），渠道**库存堰塞湖**（终端动销疲软），茅台控量稳价、以茅台 IP 扩张挤压中小品牌空间。

用五问框架读它：格局没坏（头部更集中，"月亮"更亮）但**景气位置在下行段**——所以 2025 年的正确姿势不是"无脑茅台=价值投资"，而是跟踪两个反转信号：**批价企稳 + 库存去化**。这就是块 9 马克斯"钟摆位置"判断的行业版操作：观点跟着证据走，不跟着信仰走。

### 22.4 写行业报告的骨架（可直接套用）

结论先行（一段话，可证伪）→ 证据链（数据+交叉验证）→ **与市场共识的差异**（没有差异的结论没有价值）→ 风险与证伪条件（什么情况说明我错了）。

## 23. A股 IPO 全流程与再融资工具（块23）

### 23.1 IPO 全流程（时间线通常 1-2 年以上）

改制与辅导（券商辅导备案→辅导验收）→ 申报受理 → 交易所**多轮问询**（注册制的核心环节：披露真实准确完整）→ 上市委审议（"上会"）→ 证监会注册 → 发行（网下询价定价 + 网上申购）→ 上市敲钟。投行在全程做：尽调、写招股书、答问询、定价承销。**招股书是免费的商业教科书**——想研究任何一家公司的商业模式，先读它的招股书（巨潮/交易所官网可下）。

发行机制名词：**绿鞋**（超额配售选择权，上市 30 天内稳定股价）、**战略配售**（给长线资金锁定期份额）。

### 23.2 再融资三件套对比（A股）

| 工具 | 对象 | 关键条款 | 适用 |
|---|---|---|---|
| 定增（定向增发） | 不超过 35 名特定对象 | 折价发行，限售 6 个月（控股股东 18 个月） | 最灵活，引入战投/收购配套融资 |
| 配股 | 全体老股东 10 配 X | 折价大，**必须全体股东参与**否则被摊薄 | 大股东愿意掏钱的场合 |
| 可转债 | 公众 | 债底+转股期权；有下修条款（下调转股价）、强赎条款；发行后 6 个月才可转股 | 对股价友好（发行人是"想让你转股"的债主） |

### 23.3 2024-2026 政策主线（联网核实）

2024 年 9 月"**并购六条**"+《重组办法》修订（2025 年落地）+ **简易审核程序** → A 股并购重组 2025-2026 年高景气，产业整合成为主流、龙头集中。判断：IPO 节奏受控的年份，**并购是投行业务的新主战场**——这也和块 7 的"港股成增量"互为印证。

## 24. 量化入门路径与工具链（块24）

### 24.1 心法与路径

量化 = **把投资逻辑写成可回测的代码**。第一课不是赚钱，是**防过拟合**。路径：Python（pandas/numpy）→ 免费数据（akshare/tushare）→ 回测框架 → 因子体系。

### 24.2 工具选型（联网核实的主流定位）

| 框架 | 定位 | 适合 |
|---|---|---|
| **Backtrader** | 经典事件驱动回测，简单易上手 | 入门首选，日线级别策略学习 |
| **Qlib**（微软开源） | AI 量化：因子挖掘 + 机器学习管线，预测结果可接其他平台 | 进阶 ML 量化 |
| **vn.py（veighna）** | 工程化实盘交易链路，支持 CTP 期货/tick 级 | 想接实盘/期货方向 |
| 云端平台（聚宽/BigQuant 等） | 数据+回测+模拟盘一体化，零环境搭建 | 快速验证想法 |

学习顺序建议：Backtrader 双均线策略（理解回测框架的事件流）→ 学因子（动量/价值/质量/低波动）→ 理解 IC/IR（因子有效性度量）→ 上 Qlib 跑 ML 管线。

### 24.3 回测四坑（每一个都让策略"看起来能赚钱"）

1. **未来函数**：用了当时不可能知道的数据（用年报数据时没考虑披露滞后）
2. **幸存者偏差**：股票池只用现存股票，退市/ST 的没进去
3. **交易成本忽略**：印花税+佣金+滑点，高频策略扣完成本直接归零
4. **数据窥探**：反复调参数直到回测好看——调出来的不是策略是过拟合

### 24.4 西蒙斯与文艺复兴（量化天花板）

吉姆·西蒙斯（2024 年去世），数学家转量化，文艺复兴**大奖章基金** 1988-2018 年费前年化约 66%（费后约 39%），人类投资史最高纪录——靠统计信号、短周期、严格风控和高杠杆，且**容量受限、只做自家钱**。传记《The Man Who Solved the Market》值得读：它告诉你量化的边界（大奖章不可复制，连文艺复兴自己对外部资金的产品都平庸得多）。个人量化以学习为目的，别拿学费实盘。

## 25. 大师补全：七个名字 + 中国基金经理（块25）

### 25.1 施洛斯（Walter Schloss）——"傻"方法的胜利

纯格雷厄姆烟蒂法：分散持有 100+ 只低市净率股票，从不拜访管理层、不看盘、几乎不做宏观判断，47 年年化约 20%。巴菲特称他"华尔街最诚实的人"。学习点：**不需要聪明，需要纪律和便宜**——证明格雷厄姆体系对普通人完全可复制。

名言："行情在绝望中诞生，在怀疑中成长，在乐观中成熟，在兴奋中死亡。"大萧条最低谷买进 104 只 1 美元以下的股票；全球投资先驱（日本 60 年代、新兴市场 80 年代）。学习点：**在最大悲观点买入**是一个可操作的纪律，不是一句鸡汤。

### 25.6 行为经济学双诺奖

## 26. 科技大V补全：Bezos、Karpathy、Andreessen（块26）

### 26.1 贝索斯——股东信是最好的商业课

OpenAI 创始成员、Tesla AI 前负责人。三个关键词：**"Software 2.0"**（神经网络是新的编程范式，程序员的角色从写规则变成喂数据定目标）；**nanoGPT/llm.c**（几百行代码从零实现 GPT，开源教学天花板）；他的"从零构建大模型"视频是全球公认最好的 AI 入门材料。对 CS 学生的启示：**把复杂系统拆到能亲手实现一遍**，是最高效的学习方式——和他写代码的方式一模一样。

### 26.3 Marc Andreessen——两次"吞噬"论

2011 年《软件正在吞噬世界》（Why Software Is Eating the World）预言了之后十年；后来又写《为什么 AI 会拯救世界》和 a16z 的技术乐观主义宣言。他 2007 年的经典结论对个人也有用：**"市场 > 团队 > 产品"**（The Only Thing That Matters）——一个真正的大市场能救平庸团队，反之不然。
