## 31.2 第一周 5 道起步题（数组与双指针，附参考实现）

### 1. 两数之和（哈希表，O(n)）

```python
def two_sum(nums, target):
    seen = {}                      # 值 -> 下标
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

要点：把"找配对"变成"查字典"——哈希表是空间换时间的教科书（块 24 的因子库思维同理）。

### 2. 移除有序数组重复项（双指针，原地）

```python
def remove_duplicates(nums):
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1
```

要点：快慢指针在不申请新空间的前提下维护"已处理区"——`git` 里工作区/暂存区的分界思想。

### 3. 盛最多水的容器（对撞双指针）

```python
def max_area(height):
    lo, hi, best = 0, len(height) - 1, 0
    while lo < hi:
        best = max(best, (hi - lo) * min(height[lo], height[hi]))
        if height[lo] < height[hi]:
            lo += 1
        else:
            hi -= 1
    return best
```

要点：为什么移动矮的一侧是对的？——移动高的一侧只会让宽度变小、高度不变或更小。**证明贪心的正确性**比写代码重要。

### 4. 最大子数组和（Kadane，DP 入门）

```python
def max_sub_array(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)     # 要么另起炉灶，要么续上
        best = max(best, cur)
    return best
```

要点：状态定义是"以 i 结尾的最大和"——定义对了，转移方程自己长出来。

### 5. 二分查找（含边界，回测里 bisect 的亲戚）

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

要点：`mid±1` 与循环条件 `<=` 必须配套——边界错一位是二分的头号 bug 源（块 1 的 `git bisect` 就是它的工程版）。
